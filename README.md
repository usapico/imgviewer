# ImgViewer

PNG / WebP / JPG / JPEG / GIF を開ける、Windows用の小さな画像ビューアーです。GIF・WebPのアニメーションにも対応しています。

**配布元：[USAPICO](https://usapico.com/)**  
**ダウンロード先：[GitHub Releases](https://github.com/usapico/imgviewer/releases/latest)**

ZIPを展開して `ImgViewer.exe` を起動してください。インストールや追加ランタイムは不要です。[利用条件](LICENSE.txt) に同意のうえご利用ください。

## 主な機能

- 画像をドロップ、または `Ctrl+O` で開く。
- 最初の表示は、縦横比を保って高さ **1080ピクセル以内**に調整。画面に収まらない場合はさらに縮小し、小さな画像は拡大しません。
- 同じフォルダーの画像を前後に切り替え。壊れた画像や削除済みの画像は読み飛ばします。
- 拡大・縮小、ドラッグ移動、全画面表示、アニメーションの一時停止・再開。
- 元の画像ファイルは変更しません。ローカル画像の表示にネット接続は不要です。

## 操作

| 操作 | 機能 |
| --- | --- |
| `Ctrl+O` / ドロップ | 画像を開く |
| `←` / `→` | 前 / 次の画像 |
| ホイール / `+` / `-` | 拡大・縮小 |
| 左ドラッグ | 拡大した画像を移動 |
| `0` / `1` | 画面に合わせる / 原寸表示 |
| `F11` / ダブルクリック | 全画面の切り替え |
| `Space` | アニメーションの一時停止・再開 |
| `Ctrl+W` | 画像を閉じる |
| `Esc` | 全画面を解除。通常表示中は終了 |
| `F1` | 操作ヘルプ |

## 動作環境と制限

Windows 10 バージョン1703以降 / Windows 11（x64）に対応しています。

高さ1080ピクセルの制限は、最初に表示する画像の物理ピクセル数です。開いた後は自由に拡大できます。

入力ファイルは512 MiB、画像の寸法は1億ピクセルまでです。これはアプリ全体のメモリ使用量の上限ではありません。大きな画像やアニメーションでは、読み込みに時間やメモリを必要とします。同じフォルダーの画像が1万件を超える場合は、前後の切り替えを無効にします。

配布版には電子署名がありません。Windowsや組織の設定によって警告が表示されたり、実行できない場合があります。
